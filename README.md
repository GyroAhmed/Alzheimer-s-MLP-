# Alzheimer-s-MLP-

## Notebook

The MLP experiments and SHAP explanations are in [`notebooks/MLP.ipynb`](notebooks/MLP.ipynb).

The notebook expects `data/raw/alzdata.csv`, which is not included in this repository. Place the dataset there before running the notebook.

Install the notebook dependencies with:

```bash
pip install pandas numpy scikit-learn torch shap matplotlib
```
